# Setup and use

**Use [COMPLETE_GUIDE.md](COMPLETE_GUIDE.md) for the full 0.5.3 instructions.**

That guide covers local start (gateway **8080**, DHIS2 **8081**, service **8094**), Configuration, staff search/approve, troubleshooting and production.

## Short staff workflow

1. Create or select a staff **user group** (recommended name: **Tracker Ownership Transfers**) and save it in **Configuration**.
2. **Request Transfer** — search by the configured identifier, request transfer to your centre.
3. **Transfer Requests** — owning centre approves or refuses.
4. Check **Messages** (envelope) and the in-app **Notifications** panel.
